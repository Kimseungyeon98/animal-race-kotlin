## 콘텐츠 등급 설문 참고

- 폭력·공포·성적 표현·욕설: 없음
- 도박: 실제 돈·상품·보상이 걸리지 않음. 복권 긁기·캡슐 뽑기·룰렛은 "누가 벌칙을 할지" 정하는 연출이고 구매·재화가 없음 — 설문에 사실대로 답한다
- 사용자 간 소통·개인정보 공유·위치: 없음

## 데이터 보안 섹션 참고 (6.0 광고 포함 기준)

Play Console › 앱 콘텐츠 › 데이터 보안. 광고 SDK(Google AdMob)가 처리하는 것을 적는다. 개발자가 직접 모으는 건 없음.

| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집하거나 공유하나요? | **예** (광고 SDK) |
| 전송 중 데이터 암호화 | 예 |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 앱에 계정이 없음 → "아니요"를 고르고, 광고 ID는 기기 설정에서 재설정·삭제 가능 |

| 데이터 유형 | 수집 | 공유 | 목적 |
|---|---|---|---|
| 기기 또는 기타 ID (광고 ID) | 예 | 예 (Google) | 광고 또는 마케팅, 사기 예방·보안 |
| 대략적인 위치 (IP로 추정) | 예 | 예 (Google) | 광고 또는 마케팅 |
| 앱 활동 › 앱 상호작용 (광고 노출·클릭) | 예 | 예 (Google) | 광고 또는 마케팅, 분석 |
| 앱 정보 및 성능 › 비정상 종료·진단 | 예 | 예 (Google) | 분석 |

- 모두 "처리가 일시적인가요?" → 아니요, "선택 사항인가요?" → 아니요(광고 표시에 필요)
- 정확한 문항은 Google의 AdMob 데이터 보안 안내(https://developers.google.com/admob/android/privacy/play-data-disclosure)를 기준으로 맞춘다
- 앱 콘텐츠 › **광고**도 "예, 광고가 포함되어 있습니다"로 바꾼다
