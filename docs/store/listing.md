동물 레이스: 복불복 내기 게임

```
벌칙 걸고 동물 경주! 꼴찌가 커피 쏘기, 사다리·복권·캡슐 몰아주기까지 20초 복불복 내기 게임
```

## 자세한 설명 (4000자 이내)

```
"오늘 커피는 누가 사지?" 고민될 때, 동물 레이스로 정해요!

벌칙을 걸고, 각자 응원할 동물에 이름을 붙이고, 출발!
20초 동안 방해·실수·역전이 쏟아지는 동물 경주를 함께 보며 소리 지르다 보면
꼴찌로 들어온 동물에 탄 사람이 벌칙 당첨!

■ 이런 게임이에요
• 2~10명이 함께 — 동물마다 달릴 사람 이름을 붙이면 해설·결과가 모두 이름으로
• 역전 드라마 — 끝날 때까지 아무도 몰라요
• 경기장 4종 — 초원·해변·설원·사막, 경기장마다 다른 해프닝
• 동물 20종 — 토끼·햄스터·판다·카피바라·고슴도치… 동물마다 다른 걸음걸이
• 랜덤 등수 — 꼴찌 말고 룰렛으로 뽑은 등수가 당첨
• 몰아주기 — 여러 명이 걸리면 사다리·복권·캡슐 미니게임으로 한 명에게 몰빵
• 결과 공유 카드 — 당첨 결과를 이미지 한 장으로 단톡방에
• 우리 기록 — 벌칙 왕·1등 왕·연속 당첨을 한눈에

■ 완전 공정
최종 순위는 출발하는 순간 무작위로 정해지고, 어떤 동물을 골라도 모든 순위에 같은 확률로 와요.
화려한 스킬과 역전은 모두 보는 재미를 위한 연출이에요.

■ 안심하고 쓰세요
• 실제 돈이나 아이템이 오가지 않는 친구·동료끼리의 놀이용 게임이에요
• 광고·인앱 결제 없음, 회원가입 없음
• 인터넷 없이 동작하고, 입력한 이름과 기록은 내 폰에만 저장돼요
```

- 사용자 간 소통·개인정보 공유·위치: 없음
