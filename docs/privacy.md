# 동물 레이스 개인정보처리방침

시행일: 2026년 10월 30일

「동물 레이스」(앱 ID `com.animalrace.android`, 이하 "앱")는 개인정보를 수집하거나 외부로 보내지 않습니다.

## 1. 수집하는 정보
- 앱은 회원가입·로그인이 없고, 인터넷 권한을 사용하지 않습니다.
- 광고, 분석 도구, 위치, 연락처, 카메라, 마이크를 사용하지 않습니다.

## 2. 기기 안에만 저장되는 정보
게임을 편하게 하기 위해 아래 내용을 **사용자의 기기 안에만** 저장합니다. 개발자를 포함한 누구에게도 전송되지 않습니다.
- 사용자가 직접 입력한 참가자 이름, 멤버 묶음, 벌칙 문구
- 경기 기록(최대 200판)과 효과음·배경음악 등 설정

이 정보는 앱 안의 "기록 지우기"로 지우거나, 앱을 삭제하면 함께 지워집니다.
안드로이드 기기 백업이 켜져 있으면 Google 계정 백업에 포함될 수 있으며, 이는 Google의 정책을 따릅니다.

## 3. 결과 카드 저장·공유
- **사진 저장**을 누르면 결과 카드 이미지가 기기의 사진(Pictures/AnimalRace)에 저장됩니다.
- **공유하기**를 누르면 사용자가 고른 앱(카카오톡 등)으로 이미지와 한 줄 글이 전달됩니다. 이후 처리는 그 앱의 정책을 따릅니다.
- 두 기능 모두 사용자가 직접 누를 때만 동작합니다.

## 4. 아동
앱은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.

## 5. 변경 및 문의
이 방침이 바뀌면 이 페이지에 시행일과 함께 알립니다.
문의는 Google Play 스토어의 앱 상세 화면에 있는 개발자 연락처로 보내 주세요.
