# 동물 레이스 아트 스타일

카툰 캐주얼(B안): **굵은 잉크 외곽선 + 단순한 도형 + 밝은 단색 채우기**. 그림은 전부 벡터 코드로 그린다
(이미지 생성 없음). 목표는 "작게(56dp) 봐도 누군지 알고, 크게(150dp) 봐도 허술하지 않은" 그림.

## 1. 작업 순서 (매번 이대로)

1. **레퍼런스부터.** 새 소재(장난감·소품·동물)는 사용자에게 사진/스크린샷을 먼저 받거나, 받은 게 있으면
   `docs/design/refs/`에 있는지 본다. 레퍼런스 없이 상상으로 그리면 방향이 어긋난다
   (3.14~3.18 악어 이빨: 레퍼런스 없이 옆모습 → 정면 → 물속 장난감 → 실제 장난감 사진으로 세 번 갈아엎고 결국 뺐다).
2. **레퍼런스 읽기 체크리스트**를 채팅에 먼저 적는다: 구도(정면/옆/비스듬히·내려다봄), 실루엣을 만드는 핵심 특징 3~5개,
   재질(플라스틱 광택/털/금속), 색 구성(주색·보조색·포인트), 표정. 사용자가 고개를 끄덕이면 그린다.
3. **캔버스 시안**(`.dc.html` 보드)에 SVG로 그리고 `tools/design/shoot.sh`로 PNG를 찍어 **직접 보고** 고친다.
   한 번에 끝내려 하지 말고 "렌더 → 어색한 곳 목록 → 고침"을 2~3회 돈다.
4. 사용자 확인 후 **앱으로 옮긴다**: 같은 좌표의 SVG path 문자열을 `svgPath()`로 그대로 쓴다.
5. **앱 화면을 찍어 확인**: `cd tools/verify && ./gradlew shot -Pscene=<장면>` → `build/shots/<장면>.png`를 보고
   시안과 나란히 비교한다. 없는 장면은 `tools/verify/sim/com/example/animalrace/shot/Shot.kt`에 추가.
6. 공정성 규칙: 그림·연출은 결과 확률을 절대 바꾸지 않는다 (색·모양은 장식, 결과는 시작 때 이미 정해짐).

## 2. 캐릭터 규칙 (`ui/art/AnimalArt.kt`)

- **좌표계** 200×170, 오른쪽을 본다. 머리는 오른쪽 위(x 130~195), 몸통 타원은 가운데(cx ≈ 92~100, cy ≈ 100),
  발바닥 y ≈ 146~152, **바닥 그림자** `shadow(100, 160, 60~64, 7)` = 잉크 15% 타원.
  `AnimalSprite`는 높이 = 폭 × 0.85.
- **그리는 순서**: 그림자 → 꼬리 → 먼 쪽 다리(진한 색) → 몸통 → 무늬 → 가까운 다리(몸통 위에 채우고 외곽선은 몸 밖에서만,
  `nearLeg`) → 귀 → 머리 → 주둥이 → 눈 → 코·입·수염. 모든 도형은 **채우기 → 잉크 외곽선**.
- **선 굵기**: 큰 덩어리(몸·머리·다리) 5, 발 4, 무늬·주름 3~4, 수염·입선 2. 꼬리처럼 두꺼운 선은
  잉크 12 위에 색 5를 겹쳐 그려 테두리 있는 선을 만든다.
- **잉크** `#2B2140` 한 가지. 순검정 금지.
- **색**: 동물마다 기본색 1 + 그늘색 1(기본보다 15~20% 어둡게, 먼 쪽 다리·무늬) + 밝은 포인트 1(주둥이 `#FFF1D0` 류)
  + 볼/코 분홍 `#FF8FA3`. 한 동물에 큰 면 색은 3개를 넘기지 않는다.
- **눈**: 잉크 점(r 4.5~5.5) + 위쪽 왼편 흰 하이라이트(r 1.6~2). 감정은 눈썹·눈꺼풀·입으로만.
- **실루엣 우선**: 동물을 구분하는 건 귀·꼬리·무늬·주둥이 모양. 56dp(차례 칸)에서도 보이게 특징을 과장한다.
- **달리기**: 다리는 `Pose(legA, legB, bob, wing)` 각도로만 움직인다 (몸통·머리는 bob으로 위아래).
  새 동물은 다리 회전축(px, py)을 허벅지 위쪽에 둔다.
- **스킬·피격 연출**은 `AnimalSprite.kt`의 `fxFrame`(Fx 종류별 자세·소품). 새 연출은 캐릭터 시트 보드에 먼저 그린다.

## 3. 소품·미니게임·장면 규칙

- **설계 좌표** 폭 390(폰 화면) 기준으로 그리고 앱에서는 칸 크기에 맞춰 `scale(s)` 한다 (`GachaGame.kt` 참고).
  선 굵기는 설계 좌표에서 3~5.
- 같은 잉크 외곽선 + 단색 채우기. **광택**은 흰색 35~45% 투명 굵은 선(6~10)을 둥근 면의 왼쪽 위에 한 줄.
- **재질 표현**: 플라스틱 = 광택 한 줄 + 두께감(아래쪽에 15~20% 어두운 면을 한 겹 더), 유리 = 연한 하늘색 + 흰 호,
  종이 = 크림색 + 얇은 선.
- **원근**: 앞에 있는 것일수록 크게 (예: 이빨 크기를 y에 비례), 겹치는 것은 뒤 → 앞 순서로 그린다.
- **배경은 단순하게**: 하늘색/크림/매트 같은 단색 + 장식 1~2개. 주인공(누를 것, 움직일 것)보다 튀면 안 된다.
- **누를 수 있는 것은 누를 수 있어 보이게**: 손가락 한 마디(≥ 40dp) 크기, 누를 차례면 노랑(`#FFE27A`/`Pal.Sun`) 강조,
  누른 것은 회색으로 납작하게.
- **긴장 연출 공식**: 가장자리 붉은 빛(inset glow) + 배경 살짝 어둡게 + 표정(눈꺼풀↓ 동공↓ 땀·침) + 심장박동 진동/소리.

## 5. 자주 한 실수

- 눈꺼풀을 사각형으로 덮어 눈 위로 블록이 튀어나옴 → 흰자 타원을 따라 호(arc)로 자르고 아래 변만 비스듬히.
- 요소가 공중에 뜸(눈썹이 눈 혹 위 허공에, 동물이 바닥 없이) → 무엇 위에 붙어 있는지 정하고 그 위에 얹는다.
- 혀·배경 장식이 누를 대상(이빨)을 가림 → 누를 대상은 항상 맨 앞.
- 개수가 많아질 때(최대 10명 × n) 칸이 넘침 → 최소/최대 인원 둘 다 그려 본다.
- 캔버스 보드 안 SVG `id`(clipPath·gradient)가 프레임끼리 겹침 → 프레임마다 `uid` 붙이기.
- dc 보드의 `{{값}}`에는 HTML을 넣을 수 없다 (글자만).
- 앱의 차례 칸처럼 `clip`된 상자 안에서 말풍선(깜짝!)이 잘림 → 배경은 `background(color, shape)`로, clip 없이.

## 6. 도구

```bash
# 캔버스 보드 → PNG (캔버스 artifact-files 폴더에서)
tools/design/shoot.sh <보드>.dc.html <폭> <높이> out.png
# 앱 화면 → PNG (진짜 글꼴, 390×844dp, 2배)
cd tools/verify && ./gradlew shot                # 전체: characters, fx, setup, result, ladder, lotto, gacha
cd tools/verify && ./gradlew shot -Pscene=characters
```
